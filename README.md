# Своё на AI

Telegram-канал о том, как обычный человек зарабатывает на AI и собственных проектах: кодинг, автоматизация, свои продукты, трейдинг-инструменты.

**Цель:** 5 000 подписчиков за 6 месяцев → первые 15–30 тыс. ₽/мес с рекламы и партнёрок.

## Структура
- `BRANDING.md` — позиционирование, тон, визуал, названия рубрик
- `CONTENT_PLAN.md` — стратегия, расписание, воронка роста, монетизация
- `POSTS.md` — 15 готовых постов на первый месяц
- `growth/` — где брать подписчиков, тексты для кросс-постинга

## Правила
1. Каждый пост — одна мысль + конкретный шаг, который можно сделать сегодня.
2. Никакой воды и «вдохновляющих цитат».
3. Честность важнее красивой подачи: показываем и провалы.
4. Минимум 3 поста в неделю, стабильно, без пропусков.
