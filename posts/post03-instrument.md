# Пост 3. Инструмент: чем я пользуюсь каждый день

🛠 Мой рабочий набор, всё бесплатное или почти:

— **Для кода**: VS Code + Copilot (есть бесплатная версия). Этого хватает для бытовых задач.
— **Для текстов и идей**: бесплатные веб-версии чатов. Разница с платными — в скорости и лимитах, не в качестве базовых задач.
— **Для картинок**: бесплатные генераторы + редактор в телефоне. Платить за 100 картинок в месяц ради канала — не нужно.
— **Для автоматизации**: n8n — open source, ставится локально, 500+ интеграций.
— **Для своих ботов**: LangBot (Apache-2.0) — тоже бесплатно.

Правило: **сначала бесплатное, платное — только когда упёрся в лимит и оно приносит деньги.**
