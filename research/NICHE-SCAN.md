# Разведка: где искать бизнес-модель вместо Telegram-канала

Дата: 21 ноября 2026. Три круга поиска: GitHub-скан (~33 запроса, ~350 репозиториев), проверка лицензий 38 проектов, отраслевой ресёрч.

## Почему Telegram-канал отвергнут
Канал — это актив, который растёт медленно и требует аудитории. При старте с нуля первые 3–6 месяцев он не приносит денег, а требует 3 поста в неделю. Это «работа на репутацию», а не «доход». Как единственный источник дохода — слабо.

### 3. Юридические ограничения (важно)
- **Wildberries прямо запрещает** выгружать данные из ЛК (п. 6.1.3 соглашения WB API). Легально — только официальный API из Каталога решений. С 25.09.2025 Service Secret живёт 180 дней; Personal Token нельзя использовать в облачных сервисах.
- **Ozon** с 03.12.2025 переложил ответственность за законность данных на продавца.
- **Яндекс.Метрика легальна** (п. 2.4 официального соглашения разрешает передавать доступ третьим лицам), API бесплатный — платить не за что.
- Безопасная модель: клиент сам даёт API-ключ или загружает свой выгруженный отчёт. Тогда ответственность за способ получения данных на клиенте.

## Ограничения, которые нельзя игнорировать
1. **Бюджет.** По всем кандидатам старт 10–35 тыс. ₽. У Микаэля ~10 тыс. ₽ и накопительный счёт под 12% — риск потерять проценты.
2. **Предметная экспертиза.** ГИС ЖКХ требует ЭП по ГОСТ Р 34.10-2001 + КриптоПРО. СОУТ требует знания 772н/776н. Экспертизы нет ни у кого из нас.
3. **Разрыв Web/API.** Часть сведений по ГИС ЖКХ доступна только через веб-интерфейс — полностью автоматический продукт не получится.
4. **Частота штрафов.** По ГИС ЖКХ: из 70 дел 2024–2025 лишь 7 завершились штрафом, 23 — предупреждениями. Боль не жжёт так, как кажется.
5. **Цена продажи 1 500–3 500 ₽/мес** требует 5–10 клиентов для выхода на 20–30 тыс. ₽/мес. Это 2–3 месяца продаж.

## Вывод
Одиночка без аудитории и с 10–15 тыс. ₽ старта не продаёт подписку микробизнесу заранее. Реалистичная модель — **продажа услуги «внедрение под ключ» + поддержка**, где деньги платят сразу за результат, а не за доступ к сервису.
