# Автопубликация постов

Скрипт `post_bot.py` публикует посты из папки `posts/` в ваш Telegram-канал.
Токен хранится только у вас, в переменной окружения — нигде в репозитории его нет.

## Установка

```bash
pip install requests
```

## Настройка

```bash
export TELEGRAM_TOKEN=123456789:AAH...   # токен от @BotFather
export TELEGRAM_CHANNEL=@svoe_na_ai       # юзернейм канала
```

## Команды

```bash
python3 bot/post_bot.py            # публикует следующий неопубликованный пост
python3 bot/post_bot.py --all       # публикует все неопубликованные
python3 bot/post_bot.py --dry       # показать, что будет, без публикации
python3 bot/post_bot.py --status    # что уже опубликовано
```

Первый пост (`post01-zakrep.md`) публикуется и закрепляется автоматически.

## Дальше — автозапуск

Чтобы публиковать без участия, на сервере с Python:

```bash
crontab -e
```

и добавить строку (посты по пн/ср/пт в 10:00):

```
0 10 * * 1,3,5 /usr/bin/python3 /путь/к/bot/post_bot.py >> /путь/к/bot/log.txt 2>&1
```

## Что уже опубликовано

Состояние хранится в `bot/state.json` — номера опубликованных постов. Файл можно удалить, чтобы опубликовать всё заново.
